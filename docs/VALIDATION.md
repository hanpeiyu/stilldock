# v0.2.0 验证记录

验证日期：2026-10-30。

## 自动化

- 6 项 Rust 测试：URL/目录边界、旧任务恢复与目录隔离、Live 选图编号、高清尺寸不足时回退、图片/视频成组文件命名、暂停与 Range 被忽略后的重写。
- 19 项 Node 页面测试：搜索自动展开、原生笔记读取、高清候选和 Live 流选择、缩略图按需加载、选图、当前笔记页切换、详情区折叠/恢复、首屏遮罩释放。
- Windows 本地格式检查、release 编译和 NSIS 打包。

页面测试使用模拟 DOM，不能代替 WebView2 实际布局验收。

## 实际媒体地址探测

对本机已有任务中的一张图片进行脱敏探测：网页资源为 WebP，1080×1920；对应平台高清 JPEG 资源为 3213×5712。没有将图片、用户数据或带参数的链接加入仓库。

该结果验证了一类高清地址规则可用，不代表所有笔记、所有 Live 流或每次请求都成功。程序会保留网页资源回退，且不自动判断画面中是否存在作者嵌入水印。
