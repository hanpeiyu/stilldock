# v0.5.0 验证记录

验证日期：2026-10-31。

## 自动化

- 15 项 Rust 测试：URL/目录边界、旧任务恢复与目录隔离、Live 选图编号、高清尺寸不足时拒绝降级、图片/视频成组文件命名、暂停与 Range 被忽略后的重写。
- 57 项 Node 页面测试：搜索自动展开、原生笔记读取、高清候选和 Live 流选择、缩略图按需加载、选图、当前笔记页切换、详情区折叠/恢复、首屏遮罩释放、返回搜索按钮和 Esc。
- Windows 本地格式检查、release 编译和 NSIS 打包。

页面测试使用模拟 DOM，不能代替 WebView2 实际布局验收。

## 实际媒体地址探测

对本机已有任务中的一张图片进行脱敏探测：网页资源为 WebP，1080×1920；对应平台高清 JPEG 资源为 3213×5712。没有将图片、用户数据或带参数的链接加入仓库。

该结果验证了一类高清地址规则可用，不代表所有笔记、所有 Live 流或每次请求都成功。高清候选失败会报错重试，不自动降级，且不自动判断画面中是否存在作者嵌入水印。

## 手势集成

隐藏 WebView2 fixture 通过 10 项真实 DOM 检查和原生 IPC 验证；使用注入的模拟指针事件，不访问平台或用户账号。覆盖当前图片序号、Live 数据、菜单取消、Esc 优先取消、原生关闭及动作单次发送。尚需用户实测物理鼠标/触摸板右键菜单时序。

## 保存策略

验证旧数据库迁移幂等、旧任务路径保留、缓存隔离、设置随任务固定、平铺同名文件保护、SQLite 尺寸记录、JSON 默认不生成及按需单文件导出。旧 JSON 即使不可解析也不影响已保存文件续传，并且不会被改写。

## 文件状态与修复

真实临时文件及本地 HTTP fixture 验证：文件删除/大小变化与不可访问区分；只重新下载缺失文件，正常文件无网络请求；SQLite 仍为同一任务；重关联目录全部匹配才更新，大小不符和任务正在运行时拒绝且保留原路径；更新后缓存目录与打开目录均指向新位置。侧栏测试验证历史“已完成”与本地缺失状态分别显示，存储不可访问时不出现补下按钮。

## 素材网格

8 项 Node 网格测试使用 120/400 张模拟图集，验证可见卡片数量、缩略图延迟加载、滚动回收释放图片、序号/选中状态、LIVE/下载参数、切回轮播、旧页面数据拒绝提交及手势命中；额外覆盖侧栏同步不回声、Shadow DOM 输入控件、Esc 优先级和原生隐藏弹层不误识别。

独立隐藏 WebView2 fixture 通过 21 项真实 DOM/布局检查和原生选图/手势 IPC：120 张图、卡片/视口尺寸、原详情 inert/visibility 恢复、滚动回收、关闭并立即重开预览、原生返回。fixture CSP 禁止远程图片请求，不访问账号或真实素材。尚未完成真实网站改版兼容性和长期内存压力测试。
